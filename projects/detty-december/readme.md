# DETTY DECEMBER FEST — Case Study

Static Vercel-ready HTML site. No build step required.

Part of the same portfolio system as the TEDxUNILAG 2.0 case study —
same dark ground, red accent, numbered-beat layout and click-to-zoom
lightbox, so the two live comfortably side by side.

Features:
- Responsive case-study layout
- Click any project image to open a full-screen gallery
- Previous/next navigation and keyboard controls
- Colour swatch strip with hex values in Section 03

Deploy the project as a static site on Vercel.
